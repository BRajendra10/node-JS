# 📋 Todo Manager — Full-Stack MERN Application

A clean and modern Todo Management Application built using **React**, **Tailwind CSS**, **Formik + Yup**, **Express.js**, and **Node.js**.  
This app allows users to **create, edit, delete, categorize, and manage their todos** with an elegant UI and smooth user experience.

---

## 🚀 Features

### ✅ Core Features
- ✨ Add New Todo (with Formik + Yup validation)
- 📝 Edit Existing Todos
- ❌ Delete Todos  
- 📂 Categorize Todos: *Work, Learning, Personal, Others*
- 🔍 Search Todos by Title
- 🏷️ Filter Todos by Category
- 🚦 Priority Selection (Low, Medium, High)
- 📅 Due Date Picker
- 🎨 Beautiful UI with Tailwind CSS
- 🧭 Intuitive Sidebar Navigation

### ⚙️ Technical Features
- 🔄 CRUD operations (Create, Read, Update, Delete)
- ⚡ Fast API using Express.js
- 🗄️ In-memory or JSON-based backend (extendable to MongoDB)
- 🧪 Form validation using Formik + Yup
- 🔁 Clean routing with React Router
- 📦 Reusable components (Modal, Forms, Buttons)
